🎮 HOW TO PLAY CHICKEN RUN

↔️
Move Left / Right

Press A / D or ← / → or swipe sideways to switch across 3 lanes.

⬆️
Jump Over Rocks

Press W, ↑ or Space or swipe up to leap over boulders and low hurdles.

⬇️
Slide Under Beams

Press S, ↓ or swipe down to duck and slide under hanging temple beams.

🪙
Collect Golden Coins & Eggs

Each coin adds +25 bonus points. Golden eggs grant +100 bonus and speed bursts!

💾
Real-Time API & Array DB

Scores are posted via REST API to the Core Java server and placed in descending rank inside the in-memory Java array!
